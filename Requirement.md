## Introduction

This project focuses on Manual Testing of an E-Commerce Application. The objective is to verify that the application functions correctly according to the expected requirements and provides the correct results for different user actions and inputs.

The project covers user information, product search and selection, cart, checkout, address, payment and order-related functionalities. Valid, invalid and boundary inputs will be considered wherever applicable.

## Requirements

### 1. User Information
- User Number should accept valid numeric input.
- User Name should accept valid user names.
- Mobile Number should accept a valid mobile number.
- Email ID should accept a valid email address.
- Password should accept a valid password.
- Address should accept valid address details.
- Invalid or incomplete input should display appropriate validation messages.

### 2. Product Search and Selection
- Users should be able to search for products.
- Relevant products should be displayed for valid searches.
- Users should be able to select a product and view its details.

### 3. Shopping Cart
- Users should be able to add products to the cart.
- Product quantity should be updated correctly.
- Product price and total amount should be calculated correctly.
- Users should be able to remove products from the cart.

### 4. Checkout
- Users should be able to proceed to checkout with valid information.
- Required delivery details should be validated.
- The correct order summary and total amount should be displayed.

### 5. Payment
- Users should be able to select an available payment method.
- Required payment information should be validated.
- Invalid or incomplete payment information should not allow successful payment.

### 6. Order Placement
- Users should be able to place an order after providing valid required information.
- Successful order placement should display an appropriate confirmation.
- Order details and final amount should be displayed correctly.

### 7. General Validation
- Mandatory fields should be validated.
- Valid inputs should be accepted.
- Invalid inputs should be rejected.
- Boundary values should be tested where applicable.
- Appropriate validation messages should be displayed.

## Testing Scope

The project will cover:
- Functional Testing
- Smoke Testing
- Sanity Testing
- Integration Testing
- Regression Testing

## Expected Outcome

The application should perform its intended functions correctly, accept valid inputs, reject invalid inputs and allow the user to successfully complete the required e-commerce flow.
